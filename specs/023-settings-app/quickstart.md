# Quickstart: Einstellungs-App mit Kategorien

**Spec**: [spec.md](./spec.md) | **Vertrag**: [contracts/settings-app.md](./contracts/settings-app.md)

## Automatisch

Im Worktree, in der Nix-Shell:

```bash
cargo test --manifest-path src-tauri/Cargo.toml known_devices # Geräteliste (über scripts/with-nix-host-bridge.sh)
pnpm check:settings        # Register, Orte, Zurück im Kopf, Farbschema, Alias, de/en-Texte (neu)
pnpm check:templates       # inkl. Sperrliste für Palettenfarben
pnpm check:wm-state
pnpm check:wm-navigation
pnpm check:chat-state
pnpm check:vault-lifecycle # ohne die Föderations-Tests
pnpm typecheck && pnpm typecheck:scripts && pnpm lint && pnpm format:check
pnpm test:e2e
```

Alle grün.

# Contract-Änderung an Spec 034: Regel Z14 (Einträge mit Eigentümer)

Wird beim Umsetzen in `specs/034-password-manager/contracts/access.md` übernommen (Tabelle der Regeln und
`ItemState`), mit Verweis auf Spec 038 (R2).

| Regel | Inhalt                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Quelle             |
| ----- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| Z14   | Ein Eintrag mit Eigentümer (`owner` gesetzt, eine holzi-Funktion wie `storage`) ist für jeden Aufrufer außer `User` und `Internal { feature }` mit `feature == owner` nicht vorhanden: `read_secret_item`, `update_item`, `delete_item` antworten `NotFound` (nach Z3 wie Z13), `list_headers` und die Agent-Kopfdaten lassen ihn weg, und als Quelle eines Verweises gilt er als nicht sichtbar. Keine Freigabe, auch nicht für `*`, ändert das. Den Eigentümer setzt nur holzi beim Anlegen; kein Command und keine Bridge-Methode setzt oder ändert ihn. Der Eigentümer selbst (`Internal { feature == owner }`) darf seinen Eintrag endgültig löschen (Ausnahme zu Z11, nur für eigene Einträge), damit das Entfernen einer Verbindung keine Zugangsdaten zurücklässt. | 038 FR-007, FR-012 |

`ItemState { tags, in_trash, owner: Option<&str> }`; `visible` prüft zuerst den Eigentümer, dann Z13, dann
den Bereich. Der Nutzer sieht und bearbeitet solche Einträge wie jeden anderen (Z1); die Oberfläche kennzeichnet
sie („gehört zu: Speicher“) und warnt beim Löschen über `UsageRegistry` (der Speicher meldet sich dort
als Nutzer des Eintrags).
